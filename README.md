# Alethia
Alethia is a personal AI assistant chatbot built using Streamlit, LangChain, and Groq API.

## Features
- Interactive chatbot
- Conversation history
- Groq LLM integration
- API key input
- AI-powered responses

## Requirements
- streamlit
- langchain-core
- langchain-groq

## How to Run
streamlit run Alethia.py
